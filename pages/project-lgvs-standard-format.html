Professional case · 2024–2025

Automated vehicles — Systems integration & validation

Systems integration testing, automated vehicle diagnostics and functional verification.

Engineering problem

A fleet of approximately 60 LGVs relied on navigation, safety sensing, vehicle motion and fixed automation interfaces working together.

My contribution

I diagnosed navigation and sensor issues using layouts, alarms, TwinCAT interfaces and event logs. I installed, network-configured, leveled and calibrated SICK PLS devices and verified protective-zone and alarm behavior.

Testing & verification

During final high-load system testing I monitored task execution, vehicle positions, alarms and stoppages under increased production demand. In a separate conveyor-interface fault investigation I modified existing SQL queries to reconstruct events and escalated evidence to a software engineer.

Results & limitations

The work demonstrates operational test participation, sensor verification and interface fault isolation. I did not own the full test protocol, write the underlying PLC architecture or implement the software fix. No formal automotive road test is claimed.
